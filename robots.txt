# Reachmark crawler policy
# Private application routes return X-Robots-Tag: noindex, nofollow, noarchive.
# They are intentionally NOT disallowed here: search engines must be able to
# crawl an already-indexed URL and read that header to remove it from results.
# robots.txt is not access control. Private data must remain behind authentication.
