Set these environment variables and restart the server. Use port 465 with SMTP_SECURITY=ssl when required. “Configured” does not mean credentials are verified.

Good outreach is responsible outreach.

A public email address is not blanket consent. Canadian commercial email rules (CASL) require a valid consent basis or applicable exception, sender identification, and an unsubscribe mechanism. Verify your basis before every send.

Opt-outs are blocked locally. Replies are not synced: process reply-based opt-outs using “Block outreach” on the lead. Replied and Won are manual stages.

Before public deployment, set DASHBOARD_PASSWORD, HTTPS, and a stable public URL. Preview pages are public via unguessable links.
