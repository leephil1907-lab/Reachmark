Browser and app

One Reachmark. Use it in the browser, or install it.

The website is the product. Installing it puts the same workspace on your phone or computer home screen — no App Store, no second codebase.

Open in browser
On iPhone or iPad: tap the Share button, then Add to Home Screen. On Safari for Mac: File → Add to Dock. On Chrome or Edge: click the install icon in the address bar, or the menu → Install Reachmark.

1. Browser

Works in Chrome, Edge, Safari and Firefox. Sign in, run the loop, send nothing until you approve.

Go to the site

2. Install as an app

Chrome and Edge on Windows, Mac, Linux and Android will offer Install. The icon lands next to your other apps and opens in its own window.

  1. Chrome / Edge: Install Reachmark (button above), or the browser’s install icon in the address bar.
  2. Android: Install app when prompted, or Chrome menu → Install app.
  3. iPhone / iPad: Share → Add to Home Screen.

3. Run on this computer

If you have the source, this starts the same web app locally and opens it:

python -m web.desktop

That is the downloadable application for operators who self-host. It is the browser version, running on your machine.

HTTPS is required for the install button (Chrome will not install from http except on localhost). Private workspace data is never stored in the install cache.
